## 1. 全貌讲授结构（Phase 1）

按以下骨架输出，开头不加寒暄，必须显式回应全貌三大核心问题：

```markdown
## 0. 一句话本质与白话主线
   白话主线（3–5 句直讲：要解决的问题 → 为什么难 → 核心思路 → 怎么验证）+ 难点概念清单（各一句难点）+ 遴选纪要（折叠）+ 《类比登记表》（折叠，见 §1.2；零类比直讲时为空表 + 一行「本篇没有使用类比」）
## 1. 最重要的几个部分（分层矩阵）
   | 层级 | 部分 | 回答的问题 | 性质 |  ← 表格解剖
   Tier 1 地基与核心机制（精读） / Tier 2 证据链群（评判真伪） / Tier 3 领域地图坐标
## 2. 核心关系与因果脉络链（它们之间是什么关系）
   观察 → 归因 → 设计规格 → 机制解构 → 证据闭环（文字流程图）
## 3. 基础层 vs 学习焦点排序（哪些是基础，哪些最值得关注和学习）
   (a) 前置基础与门槛要求（在此融入 Phase 0 学徒自测与补课建议）
   (b) 最值得关注与学习的 N 个焦点（按价值排序 + 遴选理由）
   (c) 批判性边界（5 条材料未证明的事，防范单方面叙事过度说服）
```

### 1.1 类比使用规约（四硬律）

叙事手法从属于理解：无论白话、类比、图解还是反例，都只是手段，唯一目的是让外行听懂目标对象本体。主线默认白话直讲——第一拍以最快让外行听懂为准自由取材（痛点直陈、具体数字、反例钩子、图示或实景先行皆可，不设固定开场句式），类比只许作为白话内部的点缀，**严禁升格为贯穿全篇的剧场、世界观或品牌**；零类比直讲（全篇不用任何类比）是合法且常见的形态，不得为凑类比而造类比。选用局部类比恪守四硬律：

1. **难点准入（Hard-Concept Gate）**：只为「白话直讲后直觉最难唤醒」的概念引入类比（难点概念于 §1.2 按难度分级识别：论文级 3–5 个、轻量 1–2 或 0 个），其余概念一律白话直讲；**严禁给白话能讲清的概念强配类比**，更严禁为覆盖全篇而扩张映射义务。
2. **一物一喻与标题禁令（Concept-Level Single Mapping）**：**同一概念在全文各处必须沿用同一类比**、仅展示其不同职责切面，**严禁一物多喻**；**同一喻体不得承载两个不同概念**（登记时须扫一遍既有条目防撞）；章节标题、图表命名与目录等导航要素**严禁使用本笔记自引入的类比域词汇**（目标域固有术语、其行业惯用隐喻如 Guardrails/垃圾回收、材料为机制自命名的隐喻词如 Tree of Thoughts 均视作目标域术语，不在此列）——标题必须承载目标域信息，不得让读者先学一套私人语言才能定位内容。
3. **贴切不硬比（High Structural Fidelity）**：类比必须与机制在深层因果关系上自然同构、符合生活常识，**严禁牵强附会的“硬比喻”**，严禁发明类比域不存在的合成道具——一旦需要「手册本身就是计算器」式混血道具才能对上机制，即证明此处类比无解释力，必须放弃类比改直讲；无贴切生活隐喻的概念直接进入术语直讲，绝不削足适履。**一票否决四判据——① 仅表面相似、因果不同构（硬比）；② 外行须先具备专业知识才懂；③ 必然诱发材料不成立的错误推论；④ 需发明合成道具——全量适用于任何类比句**：无论长短、无论用于难点概念、开篇引子还是行文点缀，命中任一即弃。
4. **极简即止与失配拦截（Graceful Fallback & Misfit Guard）**：类比只是唤醒读者第一直觉的“点火器”，**1–3 句讲完切入机制**；机制展开必须迅速回到严谨的工程术语与实测代码/数据，绝不用类比硬凑机制细节、更绝不用类比域数字换皮机制参数；每个入选类比必须在《类比登记表》写明失配边界，**仅当失配可能诱发与材料相悖的推论时**才在正文机制节内一句拦截（如「这个比方到此为止：它并不能……」），其余失配只记登记表、不进正文。

四硬律之外的三条执行红线：

- **裸讲测试**：抽 2–3 个核心机制不用任何类比、纯白话讲清（绑定 Phase 1 Learner 脉络复述与 §4.2 第一维，见 §1.2 第 6 步）；讲不清即证明该处没讲透、类比在替机制兜底，必须回炉直讲——**类比不得成为理解的必要媒介**。
- **证据链隔离**：类比域内的事实（含材料自带隐喻域的历史与行业惯例）一律不得作为目标域结论的论据，只能作解释装置（铁律 3 循证讲授不受类比影响）。
- **开篇引子例外**：材料自带天然强隐喻时，可用一段（≤5 句）作开篇引子，并须明示「此为材料自身的说法」；引子不得贯穿全篇、不得进入标题、不承担映射义务；遴选上仅过硬律 3 一票否决、免外行抽检（硬律 2 喻体防撞与「证据链隔离」红线对引子同样适用）；零类比直讲（登记表为空）时不使用引子。

### 1.2 难点概念遴选协议（脑暴-快筛）

随手拈来的类比会污染概念引入点并被下游消费（Phase 2a 规律条目、2c 考评、Phase 4 各节点缀均可能引用），故**严禁不经遴选直接落笔**。遴选对象是「逐概念局部类比」：先识别难点，再逐概念脑暴-快筛（先发散后收敛的两段式择优 [5]），登记入表；零合格候选即该概念直讲，无全场回退负担。**执行时序**：先在内部完成分层矩阵、因果链与核心争议预判草稿作为评估基准，再启动遴选；呈现仍以 §0 开篇。**难度分级**：论文与长文档识别 3–5 个难点概念（真难点不足下限时按实计，0 即零类比直讲）、每概念候选 5–10 个；轻量材料（博客短文等）降至 1–2 个或 0 个（0 个即零类比直讲）、免脑暴。**不随[输入分流裁剪](../SKILL.md#输入分流与裁剪矩阵)降级的硬底线**：一票否决快筛对任何类比句一律适用，外行抽检对登记条目一律适用（抽样口径见第 5 步）。

1. **难点识别（Gate）**：解剖完成后按导语难度分级列出「白话直讲后直觉最难唤醒」的概念（论文级 3–5 个、轻量 1–2 或 0 个；判据：讲完术语与因果后，由 Learner 代演的外行预测该机制在新场景下的行为，预测错即为难点；典型如反直觉设计决策、隐性时序约束、多角色协作），各附一句难点（读者卡在哪）。零难点即零类比直讲：仍按第 4 步产出空表与一行「本篇没有使用类比」，再直接做第 6 步裸讲终检。
2. **脑暴发散（Diverge）**：每个难点概念列举 **5–10 个**候选，记为「类比 + 一句话映射（X ↔ 机制要点）」；候选至少覆盖 **3 个生活域**（不同概念可用不同域），防止首个念头锁死 [4]；发散期只增不删、不打分，候选列满前不得定选，首个直觉候选不享有任何先验加权 [1]。
3. **快筛收敛（Converge）**：逐候选过 §1.1 硬律 3 的一票否决四判据，命中任一即淘汰；幸存者按「贴切优先 [2] → 生动 [3]」排序取首选与 1 个次选（同概念回退用），**每项须附一句映射证据**；候选全灭即该概念直讲。
4. **登记与《类比登记表》（全篇类比单一事实源）**：`| 概念 | 类比（1–3 句） | 失配边界 | 首登章节 |`，只登入选类比与失配边界——不设剧场、不编排故事线、不承担覆盖义务；登记表本体在笔记中折叠呈现、不整表进正文。**写时消费纪律**：正文任何类比句必须对应登记表既有条目（§1.1 开篇引子除外：不登记、不承担映射义务，但须明示「此为材料自身的说法」）；新增类比必须先登记（含失配边界与防撞检查）再使用；同一概念必须沿用同一类比（硬律 2）。零类比直讲时仍产出空表 + 一行「本篇没有使用类比」+ 裸讲终检记录，保住固定产物名。
5. **外行瞬时理解抽检**：抽登记表全部条目（≤3 条时全抽；>3 条时抽 3 条；空表免检），由 Learner Subagent 扮演完全外行逐条判断：「听到这个类比，你能秒懂这个概念吗？（1–5 分）」。任何一条 ≤2 分即触发：① 优先在该条「类比」栏补一层更接地气的解释（不换类比，正文引用仍守硬律 4 的 1–3 句即止）；② 复评仍 ≤2 分则弃用该类比、启用次选重跑登记（正文引用旧类比的句子同步改写为新类比或直讲）；次选也不行即该概念转直讲，并回写登记表（删除该概念条目、同步清除正文对应类比句）——凡弃用或更换类比，一律同步登记表与正文引用；回退天然有界，严禁无限回退。抽检结果记入遴选纪要。
6. **裸讲终检与失配暴露**：复用 Phase 1 Learner Subagent 脉络复述——抽 2–3 个核心机制纯白话直讲（不用任何类比；登记表非空时其中至少 1 个须为已登记类比的概念），Mentor 按 §4.4 量规判定是否讲清，讲不清即回炉该概念的直讲文本，必要时弃用该概念类比降低依赖（同样须回写登记表与正文引用），严禁以「再讲一遍类比」代替讲透机制；另对已登记类比的概念，新派一个输入仅含「概念名 + 登记类比」的 Learner（不得携带讲义或复述上下文），令其只凭类比推断该机制的一个行为、再与材料对照，推断被带偏即失配暴露，按第 5 步同序处置——启用次选重跑登记与抽检，次选也不行即该概念转直讲并回写登记表（删除条目、清除正文类比句）。

**遴选纪要（随 §0 交付）**：难点概念清单（各一句难点）；候选池「分域一行式」罗列（名称以顿号分隔，不展开）；否决项计数 + 代表例；入选条目、外行抽检得分与处置；裸讲终检结论；使用开篇引子时另附其一句一票否决结论。零类比路径的退化口径：零难点时纪要仅需「难点概念清单（空）+ 一行『本篇没有使用类比』+ 裸讲终检结论」；候选全灭时保留候选池与否决计数，入选条目与外行抽检各项免填。

### 1.3 因果链示例（Procedural Graph 实战）

```
观察：轨迹越长 agent 越失控（丢目标/乱序/重复）
  ↓ 归因
程序性一致性的责任被错误压在自由生成上
  ↓ 设计规格（四要求，全文总纲）
结构化 × 推理自由 × 响应进度 × 经验改进
  ↓ 机制
表示层（三元组+属性）→ 在线消费（定位+邻域+生成式软指导）
                     ↕ 两相解耦
                      离线进化（变异→验证门→拒绝记忆）
  ↓ 证据闭环
广度（N 基准 × M 模型）+ 深度（逐轮案例）+ 反直觉（从零进化 ≥ 专家）+ 设计自证（消融）
```

## 2. 领域规律条目格式（Phase 2a）

```
## 规律 N：<名称>（英文锚点）
**最简解释**：一句话，外行能懂（难点概念可嵌 1 句已登记类比）。
**理论锚点**：IEEE 引用 1–3 条。
**解决什么问题**：没有它会坏在哪。
**演示**：用一手材料的实证数字现场演示 + 反面演示（它被违反时的实测代价）。
```

条目完成后声明正交分解：「N 条规律恰好覆盖 X / Y / Z 维度」——分解本身就是领域地图。

## 3. 争议条目格式（Phase 2b）

```
## 争议 N：<标题>——一句话点破张力
**通俗版**：白话直陈两派各自看到什么、要什么（直讲分歧本体，不设统一剧场；两派立场原文须译成人话）。
**分歧为什么产生**：两派看到不同的失败模式（各自取样不同 → 都对）；
  指出分歧本质（如：连续谱选址问题 / 验证信号信度 / 成本结构经济学）。
**难以克服吗**：分层——资源问题 / 工程问题 / 本质难题；只对冲不可消除的要说死。
```

## 4. 严师费曼考评与学徒对抗闭环规约（Phase 2c）

本阶段通过 **Mentor**（严师）与 **Learner Subagent**（学徒）的内部高烈度攻防对抗，完成对一手材料机制的无死角检验。全程自治推进，免除用户人工答题负担（用户明确要求本人受考时由用户作答，见 [SKILL.md 边界](../SKILL.md#边界与触发契约)），对抗全集完整沉淀为知识资产。

### 4.1 资料研究范围界定规范 (Research Scope Specification)
在出题考评前，Mentor 必须先系统解剖本批材料的「研究边界」：
- **目标任务与定义域**：本批材料研究的核心问题、输入输出与架构假设是什么？
- **成立工况与最佳适用区间**：机制在何种场景、假设前提或数据分布下才能发挥最大收益？
- **明确边界与非目标（Out-of-Scope）**：资料明确**没有解决、不适用、或不能外推**的范畴（如：仅在单智能体确定性环境有效，未研究分布式并发容错；防范把局部机制误认为万能银弹）。

### 4.2 费曼三维考评题型库与出题准则 (Feynman Assessment Protocol)
Mentor 出具 3 道深度考核题，必须覆盖以下三个正交维度：
1. **白话机制转述题（外行听得懂）**：
   - 考法：要求不用任何类比、以白话直讲机制本身，将核心机制解释给完全不懂该技术的人听；允许举目标域内的具体实例（举例 ≠ 类比：目标域内举例可用，跨域映射一律禁止）。题面须显式写明「不得使用任何类比」（裸讲测试落点；Learner 输入隔离下仅见题面）。
   - 硬禁令：严禁直接照搬专业术语与论文原词；凡出现术语必须用白话自洽解释，否则判定为未过；以类比复述代替机制直讲者同样判定为未过。
2. **因果与最近邻本质差异题（知其所以然）**：
   - 考法：将本方案与业界主流 baseline 或最近邻方案（如经典方法）直接对标，要求说清“旧方案在因果链哪一步死掉，新机制是如何对症下药的”。
3. **极限场景与退化预测题（知其边界）**：
   - 考法：设计一个未在材料中直接提及的新场景、极端负载或边缘条件，要求推演机制的运行链路，并预测“它在何处会最先退化或崩溃，为什么”。

### 4.3 学徒代管作答准则 (Learner Subagent Protocol)
内置的 Learner Subagent 代表求知者与工程实战视角独立应试：
- **拒绝八股复读**：严禁机械摘抄论文结论，必须基于第一性原理展开因果推演。
- **白话通透表达**：强制以白话直讲机制本身解说因果（可辅以生活常识与已登记类比作点缀；题面明令禁用类比时除外，题面约束优先），暴露真实的推演逻辑。
- **极限勇敢推演**：针对退化预测题，必须主动指认系统最脆弱的瓶颈，推演首个崩溃点。

### 4.4 学徒薄弱点诊断量规与归因矩阵 (Weakness Diagnostic Rubric)
Mentor 在审阅学徒作答时，必须出具《薄弱点诊断》，精确归因至以下四类认知缺陷之一：
| 缺陷类型 | 表现特征 | 归因与根源 |
| :--- | :--- | :--- |
| **行话复读 (Parroting)** | 堆砌生僻技术词汇、背诵公式与架构名，或以类比复述代替机制直讲（术语干净但没讲机制本体），无法用白话解释因果 | 机械记忆或类比依赖，未建立机制本体的物理直觉与因果画面 |
| **因果断裂 (Causal Gap)** | 知道组件 A 连着组件 B，但说不清为什么必须有组件 A、拔掉会引发何种崩溃 | 知其然不知其所以然，缺乏机制推演能力 |
| **边界模糊 (Boundary Confusion)** | 忽视成立前提与研究范围，将机制误当作任何场景都适用的银弹 | 缺乏批判性思维与工程约束意识 |
| **方案混淆 (Neighbor Conflation)** | 说不清与 baseline 或替代方案的本质差异，把通用特性当成本机制特有创新 | 未看透机制的真正增量所在 |

### 4.5 针对薄弱点的充分教授三板斧 (Targeted Deep Remediation)
严师坚决不复读讲义车轱辘话，必须针对诊断出的具体薄弱点实施三板斧深度补课：
1. **具象场景点醒**：构造具体的具象场景或微冲突直观展现问题本质（可用已登记类比，不要求剧场）。
2. **第一性因果溯源**：从“如果系统里没有这个设计”开始，一步步逆向推导其不可或缺性。
3. **破坏性失败反例**：给出真实的实测崩溃案例或极限反例，看到违反该机制时的实测代价。

### 4.6 同构变式复考与出闸门禁 (Isomorphic Re-test Protocol)
- **严禁复考原题**：复考原题仅能验证短期记忆，无法验证真实理解。
- **同构变式设计**：保持底层机制与考核目标严格一致，但**完全更换业务场景、输入边界或干扰因素**。
- **出闸判定**：Learner Subagent 在变式题中回答因果清晰、边界明确、表达通俗者，方可判定门禁全绿通过，正式结业并自动放行进入 Phase 3 原型实验与破坏性验证。
- **停滞回溯**：同类缺陷连续两轮变式复考无改善时，Mentor 先回溯修订讲义或《类比登记表》（常见根因是因果链缺环、白话没讲透或类比失配带偏），再出新变式复考；门禁标准不因停滞放松。修订既有类比须先回写已落盘的 Phase 1 / 2a 对应类比处再复考，保持一物一喻；已落盘的《费曼考评实录》属历史记录、保留原文，在修订点标注「类比已修订：旧类比 → 新类比/直讲」；新增类比按 §1.2 消费纪律先登记即可。
