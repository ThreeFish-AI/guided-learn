## 1. 全貌讲授结构（Phase 1）

按以下骨架输出，开头不加寒暄，必须显式回应全貌三大核心问题：

```markdown
## 0. 一句话本质与贯穿总类比
   遴选纪要（候选池 → 否决 → 决赛圈矩阵 → 终裁）+ 《类比计划》（见 §1.2）
## 1. 最重要的几个部分（分层矩阵）
   | 层级 | 部分 | 回答的问题 | 性质 |  ← 表格解剖
   Tier 1 地基与核心机制（精读） / Tier 2 证据链群（评判真伪） / Tier 3 领域地图坐标
## 2. 核心关系与因果脉络链（它们之间是什么关系）
   观察 → 归因 → 设计规格 → 机制解构 → 证据闭环（文字流程图）
## 3. 基础层 vs 学习焦点排序（哪些是基础，哪些最值得关注和学习）
   (a) 前置基础与门槛要求（在此融入 Phase 0 学徒自测与补课建议）
   (b) 最值得关注与学习的 N 个焦点（按价值排序 + 遴选理由）
   (c) 批判性边界（5 条材料未证明的事，防范单方面叙事过度说服）
```

### 1.1 类比设计规范（认知隐喻四硬律）

1. **单一世界观贯穿（Single Theater Anchor）**：全篇必须确立唯一的宏观物理剧场（如：师傅带徒弟 / 菜谱 vs 词典 / 导航 / 数字化大厦带教），所有局部机制必须是该剧场内的子角色、工具或协作流程，**严禁跨段落剧场跳跃**。
2. **单射映射恒定（Bijective Consistency）**：**同一个技术概念在全文各段落必须始终对应同一个比喻角色**，各段落仅按机制重点展示其不同的职责切面，**严禁一物多喻**（避免读者在异构角色间频繁切换造成严重认知摩擦）。
3. **贴切不硬比（High Structural Fidelity）**：类比必须与技术机制在深层因果关系上自然同构、符合生活常识，**严禁牵强附会的“硬比喻”**；若某一纯数学或底层算法缺乏贴切的生活隐喻，宁可直接进入清晰的术语与图解，绝不削足适履。
4. **极简即止（Graceful Fallback）**：类比只是唤醒读者第一直觉的“点火器”，**1–3 句讲完切入核心**；机制展开与细节证明必须迅速回到严谨的工程术语与实测代码/数据，绝不用类比硬凑机制细节。
   - *典范示例（导航世界观）*：总类比选「导航」，局部机制映射为「GPS 定位 ↔ Match、只看前方两路口 ↔ 2-hop 邻域、副驾导航员 ↔ guidance LLM、方向盘在你手里 ↔ 软注入」——世界观统一且四个组成部分单射无缺。

### 1.2 总类比遴选协议（脑暴-重聚）

劣质总类比会系统性污染全篇（Phase 1 → 2a/2b/2c → 4 均从其取角色），故**严禁随手拈来**，必须经「发散 → 重聚 → 定锚」三步遴选 [5]。**执行时序**：先在内部完成分层矩阵、因果链与核心争议预判草稿作为评估基准，再启动遴选；呈现仍以 §0 开篇。候选下限不随[输入分流裁剪](../SKILL.md#输入分流与裁剪矩阵)降级。

1. **脑暴发散（Diverge）**：列举 **30–50 个**候选，每个记为「类比对象 + 映射方式（一句话：X ↔ 核心机制）」，同一对象的不同映射方式计为不同候选（每个对象至多 2 个，防止注水凑数）；至少覆盖 **6 个生活域**（如厨房烹饪 / 交通出行 / 城市建筑 / 体育竞技 / 医疗健康 / 餐饮零售 / 师徒教育 / 邮政物流 / 侦探破案 / 自然生态），单域 ≥3 个，防止首个念头锁死 [4]；发散期只增不删、不打分，首个直觉候选不享有任何先验加权 [1]。
2. **重聚收敛（Converge）**：
   - **聚类去重**：映射骨架（哪个日常角色对应哪个核心机制）相同的近似项合并为一簇，簇内仅保留表述最优者。
   - **一票否决**：命中任一即淘汰——① 仅表面相似、因果不同构（硬比，违反硬律 3）；② 外行须先具备专业知识才懂；③ 必然诱发材料不成立的错误推论；④ 剧场承载不了机制主线——Tier 1 核心实体过半无自然角色（违反硬律 1；个别缺口转入术语直讲区，由「覆盖」维度扣分）。
   - **五维加权评分**：幸存者逐维 1–5 分，**每项分数须附一句映射证据**，加权分 = Σ（权重 × 分），满分 5.00，取 Top 3 入决赛圈：

     | 维度 | 权重 | 判据 |
     | :--- | :--- | :--- |
     | 贴切（Structural Fidelity） | 25% | 关系与因果结构同构，而非表面属性相似 [2] |
     | 传神（Essence Capture） | 25% | 精准命中材料的核心增量或反直觉洞察，神似而非形似 |
     | 生动（Vividness） | 20% | 外行日常亲历、画面感强、一听即懂 [3] |
     | 覆盖（Coverage） | 20% | 单一剧场可承载全部 Tier 1 实体、2b 争议两派与典型失败模式 |
     | 低失配（Low Misfit） | 10% | 失配点越少、越不易诱发错误推论，得分越高 [3] |

   - **映射压力测试**：为决赛圈各起草完整「实体 ↔ 角色」映射表并试讲因果链主线，统计断点（无自然角色 / 一角多物 / 一物多角 / 需硬凑）；按「断点数（少者优）→ 加权分 → 传神分」依次比较排序，首位胜出，次位为次席、末位为季席（回退序列）。
3. **定锚与《类比计划》（全篇类比单一事实源）**：
   - **剧场设定**：一句话。
   - **单射映射表**：`| 技术实体 | 剧场角色/道具 | 同构依据 | 首登章节 |`，覆盖全部 Tier 1 实体（转入术语直讲区者标注「直讲」）。
   - **故事线编排**：沿因果脉络链（观察 → 归因 → 设计规格 → 机制 → 证据）为各章节预排剧情节点，全篇串成一个连续故事。
   - **失配边界与术语直讲区**：写明类比在何处失效，以及按硬律 3 直接术语讲解的机制清单。
   - **消费纪律**：Phase 2a「类比」行、2b「通俗版」、2c「世界观微类比」、Phase 4 各节「类比」拍一律从映射表取角色；新增实体须先登记入表再使用。
4. **学徒复述终检**：复用 Phase 1 Learner Subagent 脉络复述——复述暴露类比失配（因果被类比带偏或角色混淆）时，回退启用决赛圈次席重新定锚；次席复述再失配则启用季席，三席皆失配即判定候选池不足，补充发散后重跑重聚，严禁在同一候选池内继续回退。

**遴选纪要（随 §0 交付）**：候选池「分域一行式」罗列（名称以顿号分隔，不展开）；否决项计数 + 代表例；决赛圈评分矩阵 + 压力测试断点；一句话胜出理由与失配边界。

- [3] A. G. Harrison and D. F. Treagust, "Teaching with analogies: A case study in grade-10 optics," *Journal of Research in Science Teaching*, vol. 30, no. 10, pp. 1291–1307, 1993.

### 1.3 因果链示例（Procedural Graph 实战）

```
观察：轨迹越长 agent 越失控（丢目标/乱序/重复）
  ↓ 归因
程序性一致性的责任被错误压在自由生成上
  ↓ 设计规格（四要求，全文总纲）
结构化 × 推理自由 × 响应进度 × 经验改进
  ↓ 机制
表示层（三元组+属性）→ 在线消费（定位+邻域+生成式软指导）
                     ↕ 两相解耦
                      离线进化（变异→验证门→拒绝记忆）
  ↓ 证据闭环
广度（N 基准 × M 模型）+ 深度（逐轮案例）+ 反直觉（从零进化 ≥ 专家）+ 设计自证（消融）
```

## 2. 领域规律条目格式（Phase 2a）

```
## 规律 N：<名称>（英文锚点）
**最简解释**：一句话，外行能懂。
**理论锚点**：IEEE 引用 1–3 条。
**解决什么问题**：没有它会坏在哪。
**演示**：用一手材料的实证数字现场演示 + 反面演示（它被违反时的实测代价）。
**类比**：一句话（角色取自《类比计划》映射表）。
```

条目完成后声明正交分解：「N 条规律恰好覆盖 X / Y / Z 维度」——分解本身就是领域地图。

## 3. 争议条目格式（Phase 2b）

```
## 争议 N：<标题>——一句话点破张力
**通俗版**：承接统一世界观的生活化场景讲两派分歧（如：手册 vs 导师 / 真学习 vs 背题 / 小抄 vs 肌肉）。
**分歧为什么产生**：两派看到不同的失败模式（各自取样不同 → 都对）；

**难以克服吗**：分层——资源问题 / 工程问题 / 本质难题；只对冲不可消除的要说死。
```

## 4. 严师费曼考评与学徒对抗闭环规约（Phase 2c）

本阶段通过 **Mentor**（严师）与 **Learner Subagent**（学徒）的内部高烈度攻防对抗，完成对一手材料机制的无死角检验。全程自治推进，免除用户人工答题负担，对抗全集完整沉淀为知识资产。

### 4.1 资料研究范围界定规范 (Research Scope Specification)
在出题考评前，Mentor 必须先系统解剖本批材料的「研究边界」：
- **目标任务与定义域**：本批材料研究的核心问题、输入输出与架构假设是什么？
- **成立工况与最佳适用区间**：机制在何种场景、假设前提或数据分布下才能发挥最大收益？
- **明确边界与非目标（Out-of-Scope）**：资料明确**没有解决、不适用、或不能外推**的范畴（如：仅在单智能体确定性环境有效，未研究分布式并发容错；防范把局部机制误认为万能银弹）。

### 4.2 费曼三维考评题型库与出题准则 (Feynman Assessment Protocol)
Mentor 出具 3 道深度考核题，必须覆盖以下三个正交维度：
1. **白话机制转述题（外行听得懂）**：
   - 考法：要求借用前文统一世界观剧场或生活常识，将核心机制解释给完全不懂该技术的人听。
   - 硬禁令：严禁直接照搬专业术语与论文原词；凡出现术语必须用白话自洽解释，否则判定为未过。
2. **因果与最近邻本质差异题（知其所以然）**：
   - 考法：将本方案与业界主流 baseline 或最近邻方案（如经典方法）直接对标，要求说清“旧方案在因果链哪一步死掉，新机制是如何对症下药的”。
3. **极限场景与退化预测题（知其边界）**：
   - 考法：设计一个未在材料中直接提及的新场景、极端负载或边缘条件，要求推演机制的运行链路，并预测“它在何处会最先退化或崩溃，为什么”。

### 4.3 学徒代管作答准则 (Learner Subagent Protocol)
内置的 Learner Subagent 代表求知者与工程实战视角独立应试：
- **拒绝八股复读**：严禁机械摘抄论文结论，必须基于第一性原理展开因果推演。
- **白话通透表达**：强制代入贯穿总类比或日常生活常识解说机制，暴露真实的推演逻辑。
- **极限勇敢推演**：针对退化预测题，必须主动指认系统最脆弱的瓶颈，推演首个崩溃点。

### 4.4 学徒薄弱点诊断量规与归因矩阵 (Weakness Diagnostic Rubric)
Mentor 在审阅学徒作答时，必须出具《薄弱点诊断》，精确归因至以下四类认知缺陷之一：
| 缺陷类型 | 表现特征 | 归因与根源 |
| :--- | :--- | :--- |
| **行话复读 (Parroting)** | 堆砌生僻技术词汇、背诵公式与架构名，但无法用白话解释因果 | 机械记忆，未建立物理直觉与生活心智映射 |
| **因果断裂 (Causal Gap)** | 知道组件 A 连着组件 B，但说不清为什么必须有组件 A、拔掉会引发何种崩溃 | 知其然不知其所以然，缺乏机制推演能力 |
| **边界模糊 (Boundary Confusion)** | 忽视成立前提与研究范围，将机制误当作任何场景都适用的银弹 | 缺乏批判性思维与工程约束意识 |
| **方案混淆 (Neighbor Conflation)** | 说不清与 baseline 或替代方案的本质差异，把通用特性当成本机制特有创新 | 未看透机制的真正增量所在 |

### 4.5 针对薄弱点的充分教授三板斧 (Targeted Deep Remediation)
严师坚决不复读讲义车轱辘话，必须针对诊断出的具体薄弱点实施三板斧深度补课：
1. **世界观微类比点醒**：在全篇统一世界观剧场中引入具体的微冲突场景，直观展现问题本质。
2. **第一性因果溯源**：从“如果系统里没有这个设计”开始，一步步逆向推导其不可或缺性。
3. **破坏性失败反例**：给出真实的实测崩溃案例或极限反例，看到违反该机制时的实测代价。

### 4.6 同构变式复考与出闸门禁 (Isomorphic Re-test Protocol)
- **严禁复考原题**：复考原题仅能验证短期记忆，无法验证真实理解。
- **同构变式设计**：保持底层机制与考核目标严格一致，但**完全更换业务场景、输入边界或干扰因素**。
- **出闸判定**：Learner Subagent 在变式题中回答因果清晰、边界明确、表达通俗者，方可判定门禁全绿通过，正式结业并自动放行进入 Phase 3 原型实验与破坏性验证。
- **停滞回溯**：同类缺陷连续两轮变式复考无改善时，Mentor 先回溯修订讲义或《类比计划》（常见根因是类比失配或因果链缺环），再出新变式复考；门禁标准不因停滞放松。

## 5. 沉淀笔记文档模板（Phase 4 · 入项目 docs）

```markdown
**一句话定位** / **总类比**（附《类比计划》映射表与遴选纪要摘要）/ **怎么读这篇笔记**（三拍结构声明 + 原型位置）

## 1. 它要解决什么问题（通俗引入 + 设计规格表：规格|通俗版|对应机制）

## 3..k. 各核心机制（每节：类比 → 机制 → 原型实景[真实代码/日志引用]）
## k+1. 底层规律与核心争议（5 条规律按 §2、2~3 个争议按 §3）

## k+3. 动手实验室（运行方式 + 机制→代码行号速查 + 破坏性实验实测退化）
## k+4. 批判性边界（5 条材料未证明的事）
## k+5. 研究范围与《费曼考评实录》（Feynman Mastery Archive）
       (记录 Learner Subagent 答题、Mentor 缺陷诊断、针对性讲授与同构变式复考全通过实况)
## k+6. 用户自测与费曼研讨套件（Self-Assessment Kit for User）
       (精选 3 道面向用户的全新高阶费曼思考题与延伸追问入口，供用户在通览沉淀后自由探索)
## k+7. 与本仓的关联（链接机制映射报告与相关设计文档）
```
