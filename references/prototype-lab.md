# 最小原型实验室方法论（Phase 4）

## 设计原则

1. **位置与体量**：`.temp/<topic>-lab/`（gitignore、可随时清理、不入库），单文件优先，<500 行。
2. **纯标准库**：零第三方依赖，`uv run --no-project python <file>.py --selftest` 直跑。
3. **验证机制而非模型能力**：材料里的 LLM 角色（solver / refiner / guidance）全部用
   确定性 mock 或脚本化序列替代——原型回答「机制是否自洽」，不回答「模型是否聪明」。
   在文件头声明这一点。
4. **环境确定性**：无随机数、固定 episode 序列——同一命令永远同一日志，实验才可复现。
5. **每个核心机制一个可指认的实现单元**（函数/类），并在笔记里给出行号速查表。

## 场景设计（让机制「演」出来）

- 构造一个玩具域，覆盖 **3 类样本**：正常路径 / 陷阱路径（需要某机制才能通过）/
  边缘路径（需要另一机制才能通过）。样本分数 = 三类成功率的均值，保证「单机制提升」
  与「组合提升」都能在分数上区分。
- 脚本化的「refiner/提案器」按轮次给出编辑：至少包含——
  1. 一次**正收益编辑**（从失败复盘得出，分数上抬）；
  2. 一次**过拟合编辑**（训练集动机成立、验证集大跌，被门拦下）；
  3. 一次**命中负证据后改提次选**的编辑（演示拒绝记忆改变搜索方向）；
  4. 一次**中性编辑**（只改属性/批注，平局接受）；
  5. 一次**结构非法编辑**（环/死端，校验阶段直接拒、不跑验证）。

## selftest 纪律

- 逐轮 assert 决策类型（accept / reject / accept_tie / reject_structural）与分数。
- 输出人类可读的逐轮决策日志（每轮一行：决策 + 编辑签名 + 分数变化 + 一句话动机）。
- 结尾打印 `SELFTEST PASSED ✔`；全流程 <3 min（toy 域应在秒级）。
- 把最终产物序列化（如 JSON）落盘在 lab 目录内，证明表示层完整。

## 破坏性实验（核心教学创新）

> 目的：证明「每个组件拆掉都有具体的、可复现的坏法」。这是判别工程组合创新的试金石，
> 也是把「读过」变成「掌控」的关键一步。

方法：

1. **每次只拆一个机制**，改动控制在一两行（改一个比较符 / 删一个分支 / 跳过一项校验）。
2. 改完**真跑**，逐字记录退化日志——禁止纸面推演代替实测。
3. 意外发现照单全收（实战中「拔掉拒绝记忆」预期只是省预算，实测发现搜索不换方向、
   终态差 0.20——比预期更有讲头）。
4. 每个实验按三件套报告：**改了什么 / 实测观察到什么 / 教训一句话**。

实测范例（Procedural Graph lab）：

| 实验           | 改动            | 实测退化                                                         | 教训                                             |
| -------------- | --------------- | ---------------------------------------------------------------- | ------------------------------------------------ |
| 平局门改严格门 | `>=` → `>`      | 属性级中性改进被永久拒绝                                         | 门挡的应是退化，不是无改进                       |
| 拔掉拒绝记忆   | R3 看不到黑名单 | 重复提案再被拒一次，更好的编辑从未被发现，终态 0.80 vs 正常 1.00 | 负证据的价值是强迫搜索换方向                     |
| 关掉环校验     | 跳过环检测      | 垃圾环边以平局混入图                                             | 分数门拦不住「无害但无用」，结构校验拦的正是这类 |

## 原型 → 讲授回灌

- 把实测日志与关键中间产物（如 guidance 的完整输入提示、翻译输出）**穿插进沉淀笔记**
  的对应机制小节，标注「实际运行输出」——这是「画面感」的来源。
- 破坏性实验独立成「动手实验室」小节：运行方式 + 机制→代码行号速查 + 三件套实录。
- 提示用户亲手重跑与再拆：`cd .temp/<topic>-lab && uv run --no-project python <file>.py --selftest`。

## 卫生

- 原型写在 `.temp/`，仓库根目录不留产物（若 selftest 按相对路径写文件，注意 cwd）。
- 笔记入库时声明原型位于 `.temp/`、随清理消失、可用笔记中的日志复刻。
